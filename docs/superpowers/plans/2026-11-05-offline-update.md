# 离线覆盖更新

用户已确认：双击新版安装包，查找已有安装，保存任务并关闭旧版，备份设置，覆盖更新；模板与批次记录继续使用，旧批次不迁移渲染规则。

- 安装位置：NSIS读取历史UninstallString，兼容0.2.5及更早安装包；新安装另写InstallLocation。命令行/D可指定隔离测试目录。
- 文件事务：先在临时目录解包，检查清单、版本、目标目录和运行状态；设置备份独立保存，所有待替换或删除的程序文件先备份，再写目标。SHA校验相同的运行环境保留，避免重复备份复制数百MB。只删除旧清单内淘汰的文件，不动用户添加的文件。
- 恢复：复制失败自动恢复。进程中断留下更新记录，下一次安装先恢复；未完成时新版禁止启动。备份失败、校验失败、空间不足都在覆盖之前停止。程序备份在成功后清理；配置备份保留。
- 运行中更新：交互安装先确认，再通过WM_CLOSE让程序走已有保存进度/关闭后端链路，最多等待五分钟，不强杀。静默安装发现运行中则中止。
- 版本：禁止降级；同版本允许修复；窗口标题显示版本。
- 验证：测试先RED后GREEN。单元覆盖升级、用户文件、配置快照、旧版无清单、降级、损坏包、失败回滚、中断恢复和路径边界。实际EXE验证安装发现旧自选目录、0.2.5覆盖、设置保留、运行中关闭及任务保存；重新测试正常预览导出。

边界：不添加联网检查或自动下载。0.2.5以前版本没有文件清单，首次升级仅覆盖新版本已知路径，无法辨认的旧文件保留。文件更新失败可恢复原程序；首次启动后的业务错误不做未经用户确认的数据倒退。
