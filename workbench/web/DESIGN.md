# 套图工作台界面

这是供日常批量制图使用的离线桌面工具。保留云图工作台蓝白识别，通过工作步骤和空间位置建立层级，不引入在线字体或素材。

- 主流程固定为模板、印花、效果、导出四步，允许直接返回任一步。
- 左侧编辑当前步骤，右侧常驻预览；底部显示批次数量和当前主要操作。
- 场景配置从属于模板；方向、角度和适配从属于效果；尺寸和编码质量折叠在导出步骤。
- 独立控件包括步骤导航、模板搜索、图片选择卡、适配选项、文件夹选择器和命名示例。
- 操作蓝色 #245de8，正文 #182b49，次级文字 #5d6e85，工作区 #f4f6f9；分区用边框，避免叠加装饰阴影。
- 窗口小于 1200px 时侧栏收为图标，保留双栏；低于 780px 高度时收紧导航。最小正式桌面窗口 1060×700。
- 保留键盘焦点、方向键预览、场景排序键盘替代方式、忙碌禁用和空状态；支持 reduced motion。

复用基础样式在 yuntu.css，历史功能样式在 app.css；studio.css 集中定义新工作区和共享控件。界面不修改原 PSD，导出顺序与图层堆叠顺序分开。
