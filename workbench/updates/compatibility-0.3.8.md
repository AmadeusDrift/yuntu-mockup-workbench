# 0.3.8 PSD 效果支持范围

原 PSD 保持分层，原文件和印花不保存修改。固定背景在创建缓存时合成；依赖印花的调整、蒙版和混合仍在换图时计算。确认效果、整套预览和批量导出共用同一引擎及全批参数。

| 类别 | 支持范围 | 需要检查的边界 |
| --- | --- | --- |
| 文档 | RGB、8 位，边长 ≤8192 且总像素 ≤3200 万 | 其他色彩模式、位深和画板需先转换副本 |
| 渐变映射 | 经典实色 RGB 渐变，多色标、中点、平滑度、反向、抖动，像素蒙版与剪贴 | 噪点渐变、其他插值方法、非 RGB 色标、非完全不透明渐变明确拦截；抖动种子与 Photoshop 不同 |
| 调整层 | 色阶、点曲线和采样曲线、色相/饱和度（整体、选色、着色）、曝光、反相、色调分离、阈值；保留原亮度/对比度 | 调整层要求普通模式且无自身图层样式；非默认颜色管理/特殊参数可能有差异，导入后会提示核对 |
| 混合模式 | 普通、正片叠底、滤色、柔光、变暗、变亮、叠加、强光、差值、排除、颜色减淡/加深、线性减淡/加深 | 非 100% 填充不透明度仍明确拦截；部分复杂模式尚未支持 |
| 印花与剪贴 | 母稿同源智能对象、透视、已有可支持的网格、像素/支持的矢量蒙版，静态或动态剪贴基层 | 剪贴基层要求 100% 不透明度；复杂曲面、产品智能滤镜、复杂剪贴组合会列出具体层 |
| 图层样式与其他 | 原有简单投影、固定层普通颜色叠加、下层灰度混合颜色带 | 复杂组样式、挖空、额外蒙版浓度/羽化、复杂投影、其他填充/调整类型明确拦截 |

兼容报告绑定 PSD 内容和场景配置。更新前留下的黄色警告不会直接当成新版失败结果。已有模板首次使用自动重检；重新导入同一份未修改的 PSD 会保留场景顺序、换图对象及左右对应关系。修改场景设置后重新检查，选择“不导出”的场景不参与检查。

已知不支持的模板在预览、编辑和批量任务启动前拦截；尚未检查的模板先准备缓存。批量导出会先检查全部选中模板，通过后才创建输出。隐藏内容和空基层上不参与成像的剪贴效果不会误报。

本版对用户提供的黑色金属圆牌模板做了七场景 Photoshop 原生对照、两张不同印花的十四张预览/导出对比；另有七类调整的原生色阶图对照。这些验证不表示所有 Photoshop 功能或所有参数组合都已兼容。
