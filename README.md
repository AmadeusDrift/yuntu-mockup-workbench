# 套图工作台

离线 Windows 桌面 PSD 批量套图工具，当前版本 **0.3.3**。界面沿用云图工作台的蓝白样式，桌面窗口使用 Electron，本地 Python 引擎负责 PSD 解析和批量导出。图片不需要上传到在线服务。

0.3.1 新增软件内更新：每天首次启动检查新版，点击“立即更新”后下载、校验、安装并重启，也可手动检查。断网不影响套图。0.3.0 及更早版本需要先手动安装一次 0.3.1，之后可直接在软件内更新。安装前保存正在运行的任务，保存失败会停止更新；模板、设置及批次记录保留。

## 使用流程

界面按四步组织：**选择模板 → 选择印花 → 确认效果 → 批量导出**。可随时点击步骤返回修改，右侧预览一直保留，底部显示已选素材和预计导出数量。

0.3.0 新增模板名称搜索、适配模式选项卡、组合文件夹选择控件和常驻操作栏。场景设置位于第一步，方向与任意角度位于第三步，保存位置、命名和高级导出参数位于第四步。支持 1060×700 起的桌面窗口。

- 自动查找母稿及同源智能对象，不要求统一命名为 `product`；识别不准时可手动选择图层。
- 模板与印花都支持缩略图预览，支持多模板批量处理。
- 默认自动匹配印区横竖方向，再适配，沿用 PSD 原尺寸；满版图等比铺满，透明图案去外围透明边后完整放入。
- 可手动选方向并输入任意角度；印花在固定印区内旋转，保留样机的倾斜、透视和蒙版；支持参照V7脚本去外围白边后铺满。
- 固定场景仍输出到每套产品中，同一批次只编码一次，然后复制。
- PSD 首次使用建立缓存，后续重复使用；磁盘缓存按容量与最近使用时间清理，内存中只保留当前模板渲染器。
- 支持暂停、停止保存进度、继续批次；两个产品并行处理。
- 文件夹可用原名、001顺序编号或自定义规则；图片默认01、02编号。
- 场景可拖动调整导出顺序并保存，原PSD不变；大图预览支持左右方向键切换。
- 新版安装包自动找回旧安装位置，更新前备份设置、等待保存并关闭旧版；支持文件更新失败恢复和中断后重新安装恢复，阻止降级，同版本可修复。

## 本机开发和测试

仓库仅保存源码。原便携软件的 Python 运行环境、第三方 vendor 依赖、PSD、印花、缓存、用户配置和 `release/` 安装包不上传。

现有 Windows 工程使用如下目录，保留已有运行环境即可复现本机测试：

```text
工程目录/
  workbench/
  通用PSD高速套图_正片叠底_2套并行便携版/
    runtime/python.exe
    vendor/
```

在工程根目录用 PowerShell 执行：

```powershell
& '.\通用PSD高速套图_正片叠底_2套并行便携版\runtime\python.exe' -I -B '.\workbench\tests\run.py'
```

若运行环境放在其他位置，设置 `MOCKUP_RUNTIME_ROOT` 指向含 `runtime/` 和 `vendor/` 的目录。`requirements.txt` 记录当前核心 Python 依赖版本；当前构建脚本仍依赖上述已准备好的便携运行环境，不会自动下载或建立环境。

## 构建 EXE

在现有 Windows 构建机上执行：

```powershell
& '.\通用PSD高速套图_正片叠底_2套并行便携版\runtime\python.exe' -I -B '.\workbench\desktop\build.py'
```

当前离线脚本需要本机已缓存的官方 Electron `45.1.0` Windows x64 ZIP，以及 electron-builder 缓存中的 NSIS `3.0.4.1`。通用安装包使用空白模板目录，不包含构建电脑的 PSD 路径、缩略图或个人设置。构建脚本使用的具体缓存路径见 `build.py`。

输出为 `release/套图工作台-v0.3.3/套图工作台.exe` 和 `release/套图工作台安装.exe`。把安装 EXE 复制到其他 Windows 10/11 x64 电脑后，双击安装即可，无需另装 Python、Photoshop 或 Electron；PSD 和印花素材另行复制并导入。便携版需要保留整个文件夹；安装后可从桌面图标启动。根目录的 `启动套图工作台.bat` 用于启动已经构建好的便携版。

## 验证与限制

0.3.1通过85项套图测试和6项更新客户端测试。最终安装包的3220个文件已逐一校验；在空白个人目录启动真实EXE，完成七场景预览和两张印花共14张导出。桌面脚本验证四步切换、模板搜索、适配选项、拖动排序、命名、大图方向键，以及输入角度后第一次鼠标点击切步。1520×960和1060×700窗口均检查了布局与图片加载。

`workbench/desktop/test-workflow.cjs` 是实际桌面回归脚本，通过本机9341调试端口连接测试EXE。参数为测试个人目录、测试资源与输出根目录、原顺序场景3的JPG基准；夹具要求一个七场景模板和两张相同印花。仅连接隔离测试实例，勿指向生产批次。

自动测试覆盖横竖方向、任意角度、45°样机固定边界、缩小过滤、旧批次兼容和离线更新恢复。此前已用13份本地PSD验证91个场景；真实PSD验收需要本地模板，不随仓库提供。

0.2.6通过85项自动测试，并在隔离目录实测0.2.5升级：保存暂停任务、退出后台、保留模板与偏好、验证配置备份、恢复旧批次12张印花共84张成品。实际安装包已验证旧自选目录发现、同版本修复和降级拦截；最终安装包解包3215个文件逐一校验，并通过桌面预览和导出检查。报告在本地release/update-verification.json及release/transfer-verification.json。

自动适配按透明度与比例判断，不能识别图片主体和文字。特殊构图可在“确认效果”步骤里调整。多场景模板推荐使用顶层数字场景组；陌生 PSD 的复杂滤镜和组效果仍可能不支持，导出前先预览。尚未完成全部场景与 Photoshop 的逐像素对比。

来源说明见 [workbench/SOURCE.md](workbench/SOURCE.md)，操作说明见 [使用套图工作台.md](使用套图工作台.md)。仓库包含基于原便携软件修改的引擎和复用的界面样式，未新增开源许可声明。

## 0.3.3 子目录与三联画

支持递归读取印花子目录。同款目录中左、中、右（或 left/center/right）三张印花各自生成完整轮播图，忽略同目录的三联总预览图。无需设置模板的左中右印区。

例如一个款式使用七场景模板，输出为 `款式名/左/01.png … 07.png`、`款式名/中/01.png … 07.png`、`款式名/右/01.png … 07.png`。产品顺序编号按款式递增，三张印花共享外层款式编号。断点续跑分别保存每张印花的进度。

95项自动测试覆盖独立套图、七场景共42张输出、顺序命名、预览图排除和断点续跑。
